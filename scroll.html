Scroll · Words

Words. Each word lights up as you read your way down.

A first draft is meant to be wrong. You sketch it in pencil so it costs nothing to throw away, and you keep throwing it away until what's left is worth keeping. Then you commit: the lines get inked, the colour goes in, and the thing ships. Every effect here is that moment, drawn out over a scroll.

import { words } from '@brightkumedzro/reveal/scroll';
words('#manifesto');

Scroll · Lines

Lines that draw themselves. Any SVG, drawn along its own paths as it scrolls into view: diagrams, maps, signatures, journeys.

import { lines } from '@brightkumedzro/reveal/scroll';

lines('#journey');                                   // every path draws in order, as it scrolls in
lines('#map', { order: 'together', fill: true });   // all at once, fills fading in after
lines('#signature', { pen: '#33adff' });               // a dot rides the tip

Scroll · Steps

A story told in steps. One visual stays put while the steps scroll past, and it changes with each one.

01 · Discover
02 · Define
03 · Design
04 · Deliver

  1. 01Discover

    Talk to the people who'll use it, and to the people who'll pay for it. Collect what hurts, what's been tried and what success would look like.

  2. 02Define

    Turn it into one problem worth solving, a way to measure it, and what's out of scope. Everyone signs up to the same target.

  3. 03Design

    Sketch, prototype and test the riskiest part first. Wireframes become a clickable flow, then a design system the team can build from.

  4. 04Deliver

    Ship the first complete cycle, measure it against the target, and keep improving what's live instead of polishing what isn't.

// </section>

Scroll · Scrub

Frame scrub. Scroll plays an image sequence forwards and backwards, like a product page.

Here it plays 90 frames of the fire reveal. Scroll down and the comet comes in; scroll up and it un-burns.

Frame 1 / 90

import { scrub } from '@brightkumedzro/reveal/scroll';

// a tall section; its stage stays pinned while it scrolls past
scrub('.product', {
  frames: '/frames/%03d.jpg', count: 90,   // or an array of URLs, or video: '/clip.mp4'
  fit: 'cover',
  alt: 'The phone turning round',
});

Reveal · Scroll effects

Add them to your page. One import, then point each effect at your own content.

import { words, count, lines, mask, steps, scrub, zoom } from '@brightkumedzro/reveal/scroll';

Every effect returns { stop() } to undo itself, shares one scroll listener with the others, and is safe to import during server rendering. With reduced motion turned on, each one simply shows its finished state, and screen readers always get the real text.
