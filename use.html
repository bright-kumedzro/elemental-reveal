Drag the slider, or press play. Click the image too: every effect does something different where you click.

Add it

Install it from npm, or import it straight from a CDN with no build step. Give an element a size, then call reveal on it with the two images.

npm install @brightkumedzro/reveal
<!-- the effect fills this box; anything you put inside stays on top -->
<div id="hero" style="height: 80vh"></div>

<script type="module">
  import { reveal } from 'https://cdn.jsdelivr.net/npm/@brightkumedzro/reveal@1/js/lib.js';
  // or, after npm install: import { reveal } from '@brightkumedzro/reveal';

  reveal('#hero', {
    effect: 'water',          // any of the seventeen, by name
    from: '/sketch.png',      // what gets taken away
    to: '/final.png',        // what's revealed
  });
</script>

By default it follows the scroll: the reveal runs as the element rises through the screen. The version in the URL is pinned, so an update never changes your page until you bump it. Images from another domain need CORS headers, or they can't be drawn into WebGL.

Just one pack

The main import has every effect. If you only use one pack, import that pack instead for a smaller bundle:

import { reveal } from '@brightkumedzro/reveal/elemental';   // fire · water · air · earth · lightning · frost
import { reveal } from '@brightkumedzro/reveal/shinobi';     // clone · vortex · spiral · blade · storm · twister · magma · shuriken
import { reveal } from '@brightkumedzro/reveal/paper';       // curl · fold · draw
// from the CDN: …/@brightkumedzro/reveal@1/js/elemental/index.js or …/js/shinobi/index.js

Coming from @brightkumedzro/elemental-reveal? It's the same library under a new name. Swap the import for @brightkumedzro/reveal/elemental and everything works as before.

Three ways to drive it

// 1. Scroll (default). Or pin it in a tall wrapper, like the chapters on this site:
reveal('#stage', { effect: 'fire', from, to, track: '#tall-wrapper' });
//    #tall-wrapper { height: 400vh }   #stage { position: sticky; top: 0; height: 100vh }

// 2. Plays once when it comes into view
reveal('#card', { effect: 'lightning', from, to, progress: 'auto', duration: 3000 });

// 3. You set it: a slider, a video's currentTime, a step in a form…
const fx = reveal('#box', { effect: 'earth', from, to, progress: 'manual' });
fx.progress(0.5);

Options

OptionDefaultWhat it does
effect'fire''fire', 'water', 'air', 'earth', 'lightning', 'frost' (elemental), 'clone', 'vortex', 'spiral', 'blade', 'storm', 'twister', 'magma', 'shuriken' (shinobi) or 'curl', 'fold', 'draw' (paper). A pack's import defaults to its first effect.
fromrequiredWhat gets taken away: an image URL, or an <img>, <canvas> or <video>.
torequiredWhat's revealed underneath. Same types as from.
progress'scroll''scroll' follows the page, 'auto' plays once when it comes into view, and 'manual' waits for fx.progress(p).
tracknoneScroll mode: a tall wrapper the element is pinned inside. Progress runs from the wrapper's top reaching the top of the screen to its bottom reaching the bottom.
duration3500Auto mode: how long it takes, in milliseconds.
interactivetrueHover and click effects.
fit'cover'How the images fill the element: 'cover', 'contain' or 'fill', like CSS object-fit.
background'#0b0b0c'Shown behind images that don't fill the element.
sound'off'Synthesised sound, no audio files. 'on' starts at the visitor's first click, tap or key press. 'toggle' waits for fx.sound(true) or any button with a data-reveal-sound attribute.
onProgressnoneCalled every frame with progress from 0 to 1. The draft is gone by about 0.9.
credittrueOne line crediting the library in the browser console. false turns it off.

What you get back

const fx = reveal(…);
await fx.ready;      // both images loaded, first frame drawn
fx.progress();       // read progress
fx.progress(0.3);    // set it (switches to manual)
fx.play();           // run it from the start over `duration`
fx.reset();          // put the draft back and clear clicks
fx.sound(true);      // turn sound on or off for every reveal on the page
fx.destroy();        // remove the canvases and listeners

Good to know

  • Each call gets its own WebGL2 canvas. Browsers cap how many can run at once (often around 16), so a few per page is fine. Call destroy() on ones you're done with.
  • Without WebGL2 it falls back to a wipe. With reduced motion turned on, it cross-fades, so lightning doesn't flash.
  • Anything inside the element stays on top of the effect, so it works as a background behind your own headline or buttons.
  • On slow devices it drops its render resolution automatically until it's smooth.

Privacy

The library makes no network requests of its own: it only loads the images you give it, and it sends nothing about you or your visitors anywhere. Using it on a site? Submit it to be listed under “Made with Reveal”.
